# 🍀 Clover Idle Story — คู่มือและระบบเกมอย่างเป็นทางการ

ยินดีต้อนรับสู่คลังข้อมูลและคู่มือระบบเกม **Clover Idle Story (KMS v232.2)** แหล่งรวบรวมข้อมูลระบบเกม, คำสั่งอำนวยความสะดวก, การตั้งค่าบอทช่วยเล่น (Auto Play), ระบบสัตว์เลี้ยง และการพัฒนาตัวละคร

---

## 🌟 ข้อมูลทั่วไปเกี่ยวกับเซิร์ฟเวอร์
* **เวอร์ชันไคลเอนต์:** KMS v232.2 (รองรับภาษาไทย / Thai Chat & Font Support)
* **รูปแบบการเล่น:** Fantasy MMORPG ผสมผสานระบบ Idle Progression ช่วยฟาร์มและเก็บเลเวลอย่างสะดวกสบาย
* **จำนวนอาชีพ:** ครบทั้ง 50 อาชีพ (Explorer, Cygnus Knights, Heroes, Resistance, Nova, Flora, Anima และ Regional Classes)
* **ระบบพิเศษเฉพาะเซิร์ฟเวอร์:**
  * 🤖 **Official Auto Play (`@bot` / `@autoplay`):** ระบบช่วยเล่นอัตโนมัติอัจฉริยะ ล็อคเป้าและกดสกิลตามช่องคีย์ลัด **1 ถึง 4 (Slots 1-4)** *(ต้องมีไอเทม Merchant Blessing ก่อนใช้งาน)*
  * 🐾 **Map-Wide Pet AutoLoot (Item ID: 5190015):** สัตว์เลี้ยงดูดของทั้งแมพ ไม่ต้องเดินเก็บเอง
  * 🛡️ **Merchant Blessing (Item ID: 5190016):** บัฟโบนัส +50% EXP / Drop / Meso และเป็นเงื่อนไขจำเป็นสำหรับเปิดบอท `@bot`
  * 💬 **Thai Chat Integration:** รองรับการพิมพ์และการแสดงผลฟอนต์ภาษาไทยสมบูรณ์แบบ
