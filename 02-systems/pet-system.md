# 🐾 ระบบสัตว์เลี้ยง & สกิลสัตว์เลี้ยงทั้งหมด (All Pet Skills)

ใน **Clover Idle Story** สัตว์เลี้ยงมีระบบสกิลเสริมความสามารถที่ครบครันที่สุด ครอบคลุมตั้งแต่การเก็บของ, การกดบัฟ, การกินยา ไปจนถึงการเปิดร้านค้าของชำในตัว

---

## 🌟 1. สกิลไฮไลท์ระดับสูงสุด: Map-Wide AutoLoot

<img src="../assets/Autoloot_32x32.png" width="32" height="32" alt="AutoLoot Icon" /> **Map-Wide Pickup / AutoLoot (ดูดของทั้งแผนที่)**
* **Item ID:** `5190015` (และ `5190008`)
* **คุณสมบัติ:**
  * ทำให้สัตว์เลี้ยงสามารถ**ดูดเก็บไอเทมและเงิน Meso ที่ตกอยู่ทุกจุดในแผนที่เข้ามาให้ผู้เล่นทันทีแบบไร้ขีดจำกัดระยะทาง**
  * ไม่ว่ามอนสเตอร์จะตายบนที่สูง ชั้นล่างสุด หรือนอกจอ สัตว์เลี้ยงจะดึงไอเทมเข้าตัวทันที
  * สามารถใช้ได้กับสัตว์เลี้ยงทุกชนิด

## 📜 2. รายการสกิลสัตว์เลี้ยงทั้งหมดในระบบเกม (Pet Skill Catalog)

| Item ID | ชื่อสกิลสัตว์เลี้ยง | คุณสมบัติและความสามารถ |
| :---: | :--- | :--- |
| **`5190015`** | **Map-Wide AutoLoot Skill** | **ดูดเงินและไอเทมทั่วทั้งแผนที่อัตโนมัติแบบไร้ระยะทาง** |
| **`5190010`** | **Auto Buff Skill** | ลากสกิลบัฟของตัวละครมาใส่ที่ตัวสัตว์เลี้ยงได้สูงสุด **2 สกิลต่อตัว** สัตว์เลี้ยงจะร่ายบัฟให้อัตโนมัติเมื่อบัฟหมดเวลา |
| **`5190001`** | **Auto HP Potion Skill** | เติมยาฟื้นฟูพลังชีวิต (HP) ให้ตัวละครทันทีเมื่อหลอดเลือดลดลงถึงเกณฑ์ที่ตั้งไว้ |
| **`5190006`** | **Auto MP Potion Skill** | เติมยาฟื้นฟูพลังเวท (MP) ให้ตัวละครทันทีเมื่อหลอดมานาลดลงถึงเกณฑ์ที่ตั้งไว้ |
| **`5190009`** | **Auto All Cure Skill** | ใช้ยา All Cure Potion ลบล้างสถานะผิดปกติ (เช่น ติดพิษ, ใบ้, คำสาป) ให้ผู้เล่นทันที |
| **`5190011`** | **Auto Feed & Movement Skill** | สัตว์เลี้ยงจะกินอาหารสัตว์เลี้ยง (Pet Food) จากกระเป๋าเองเมื่อหิว และสามารถปีนบันได/ขึ้นลงชั้นเพื่อเก็บของได้ |
| **`5190002`** | **Expanded Auto Move Skill** | ขยายระยะรัศมีการวิ่งเข้าหาไอเทมของสัตว์เลี้ยงกว้างขึ้นถึง **3 เท่า (3x Range)** |
| **`5190003`** | **Auto Move Skill** | สัตว์เลี้ยงจะขยับตัวเข้าหาและเก็บไอเทม/เงิน Meso ในบริเวณใกล้เคียงโดยอัตโนมัติ |
| **`5190000`** | **Item Pouch Skill** | มอบความสามารถในการเก็บไอเทมทั่วไปเข้ากระเป๋าให้กับสัตว์เลี้ยง |
| **`5190004`** | **Expired Pickup Skill** | สัตว์เลี้ยงสามารถเก็บไอเทมของผู้เล่นคนอื่นที่ดรอปทิ้งไว้เกินเวลา (110 วินาที) ได้ |
| **`5190005`** | **Ignore Item Skill** | ตั้งค่า "ฟิลเตอร์ยกเว้นไอเทม" เพื่อสั่งให้สัตว์เลี้ยงไม่ต้องเก็บไอเทมขยะที่เราไม่ต้องการ |
| **`5190012`** | **Fatten Up Skill** | สัตว์เลี้ยงจะตัวใหญ่ขึ้นเมื่อกำจัดมอนสเตอร์ใกล้เลเวลตัวละคร และจะสุ่มร่ายบัฟพิเศษลึกลับให้ทุก 5 นาที |
| **`5190013`** | **Open Pet Shop Skill** | สัตว์เลี้ยงกลายเป็นร้านขายของชำเคลื่อนที่ สามารถกดเปิดซื้อยา HP/MP หรือเติมดาวกระจายและกระสุนปืนได้จากทุกที่ |
| **`5190014`** | **Slimming Medicine** | ยาแก้สำหรับสัตว์เลี้ยงที่ใช้สกิล Fatten Up เพื่อลดขนาดตัวกลับมาเป็นปกติ |

## ❌ 3. สกิลสำหรับลบความสามารถสัตว์เลี้ยง (Delete Skill Scrolls)

หากต้องการรีเซ็ตหรือยกเลิกความสามารถบางอย่างของสัตว์เลี้ยง สามารถใช้ Scroll ดังต่อไปนี้:
* **`5191000` (- Delete Item Pick-Up):** ลบความสามารถในการเก็บไอเทม
* **`5191001` (- Delete HP Charge):** ลบความสามารถในการเติมยา HP อัตโนมัติ
* **`5191002` (- Delete Expand Range):** รีเซ็ตระยะการวิ่งเก็บของกลับมาเป็นขนาดปกติ
* **`5191003` (- Delete Automatic Pick-Up):** ปิดการเคลื่อนที่เก็บของอัตโนมัติ
* **`5191004` (- Delete Pick up Leftover Item):** ปิดการเก็บของตกค้างของผู้เล่นอื่น

## 🐾 4. การใช้สัตว์เลี้ยง 3 ตัวพร้อมกัน (Multi-Pet System)
* ผู้เล่นสามารถใช้งานสัตว์เลี้ยงพร้อมกันได้สูงสุด **3 ตัว**
* ด้วยการติดตั้งสกิล **Auto Buff (`5190010`)** ให้ครบทั้ง 3 ตัว จะทำให้คุณมีช่องใส่สกิลบัฟอัตโนมัติมากถึง **6 สกิล** ทำให้ไม่ต้องเสียเวลากดบัฟเองในขณะฟาร์มด้วยระบบ `@autoplay`!
