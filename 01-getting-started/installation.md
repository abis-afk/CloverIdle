# 📥 การดาวน์โหลด & ตั้งค่าเกม

ขั้นตอนการดาวน์โหลด ติดตั้งตัวเกม Clover Idle Story และการแก้ปัญหาเบื้องต้นในการเข้าเกม

---

## 🛠️ ขั้นตอนการติดตั้งและเข้าเกม

1. **ดาวน์โหลดตัวเกม:**
   * ดาวน์โหลดตัวเกมเวอร์ชันล่าสุดจากหน้าเว็บไซต์หลักหรือลิงก์ของเซิร์ฟเวอร์
   * แตกไฟล์ ZIP ไปยังไดรฟ์ที่ต้องการ (แนะนำให้แตกไฟล์ไว้ที่ `C:\Clover` หรือ `D:\Clover` หลีกเลี่ยงเส้นทางที่มีโฟลเดอร์ภาษาไทยหรือโฟลเดอร์ซ้อนกันหลายชั้น)

2. **เปิดเกมผ่าน Launcher:**
   * ดับเบิ้ลคลิกเปิดโปรแกรม **`Clover Launcher.exe`** (หรือดับเบิ้ลคลิก `START_CLOVER_THAI.bat`)
   * **สำคัญ:** ห้ามดับเบิ้ลคลิกเปิดจาก `MapleStory.exe` ตรงๆ เนื่องจากตัวเกมต้องรับ Token ยืนยันตัวตนจาก Launcher
   * กรอก Username และ Password ของคุณ จากนั้นกดปุ่ม **PLAY**

3. **เข้าสู่โลกเกม:**
   * ตัวเกมจะเปิดขึ้นในโหมดหน้าต่าง (Windowed Mode) พร้อมระบบภาษาไทย

---

## ⚠️ การแก้ปัญหาเบื้องต้นที่พบบ่อย

### ปัญหาที่ 1: เข้าเกมแล้วขึ้นจอขาวสักพักแล้วเด้งดับ
* **สาเหตุที่ 1 (Discord Overlay):** โปรแกรม Discord เปิดฟังก์ชัน In-Game Overlay ไว้ ซึ่งจะขัดแย้งกับ Direct3D 9 ของตัวเกม
  * *วิธีแก้:* เปิด Discord ➔ Settings (ฟันเฟือง) ➔ Game Overlay ➔ ปรับปิด **"Enable In-Game Overlay"**
* **สาเหตุที่ 2 (เวอร์ชันไม่ตรงกัน):** ตัวเกมในเครื่องเป็นคนละเวอร์ชันกับ Server ให้ทำการเปิด Launcher เพื่อดาวน์โหลดแพตช์ล่าสุด

### ปัญหาที่ 2: ภาษาไทยในเกมเป็นเครื่องหมายคำถาม (???)
* ตัวเกม Clover มีระบบ ThaiChat ติดตั้งมาในตัว ตรวจสอบให้แน่ใจว่าไฟล์ `clover-diagnostics.ini` ตั้งค่า `disableThai=0`
