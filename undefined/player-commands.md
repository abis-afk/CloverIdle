# คำสั่งพิมพ์ในเกม (@commands)

ผู้เล่นสามารถพิมพ์คำสั่งในช่องแชท (General Chat) โดยขึ้นต้นด้วยเครื่องหมาย `@` เพื่อเปิดเมนู หรือใช้ฟังก์ชันอำนวยความสะดวกต่างๆ ได้ทันที

***

## 📋 รายการคำสั่งทั้งหมดสำหรับผู้เล่น

| คำสั่ง          | คำสั่งย่อ / อื่นๆ     | คำอธิบายการทำงาน                                                                                                       |
| --------------- | --------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| **`@bot`**      | `@autoplay`           | **เปิด / ปิด ระบบบอทช่วยฟาร์มอัตโนมัติ** ล็อคเป้าและกดสกิลตามช่อง **1 ถึง 4 (Slots 1-4)** _(ต้องมี Merchant Blessing)_ |
| **`@check`**    | -                     | ตรวจสอบข้อมูลสเตตัสตัวละคร และข้อมูลระบบต่างๆ                                                                          |
| **`@inspect`**  | -                     | ตรวจสอบรายละเอียดค่าสถานะและอุปกรณ์                                                                                    |
| **`@mobinfo`**  | `@mi`                 | ดูข้อมูลมอนสเตอร์ในแผนที่ปัจจุบัน (HP, EXP, การดรอป)                                                                   |
| **`@lifeinfo`** | `@li`                 | ดูข้อมูลสิ่งมีชีวิต/NPC/มอนสเตอร์ทั้งหมดในแผนที่                                                                       |
| **`@boss`**     | `@bossinfo`           | ตรวจสอบสถานะการลงบอสประจำวัน และคูลดาวน์รอบเข้าบอส                                                                     |

| **`@starter`**  | `@gift`, `@checkgift` | รับกล่องของขวัญสำหรับผู้เล่นเริ่มต้น (Starter Gift)                                                                    |

| **`@fixquest`** | `@fq`                 | แก้ปัญหาเควสต์ค้าง หรือแก้ไขสถานะเควสต์ที่มีปัญหา                                                                      |

## 💡 ตัวอย่างการใช้งานคำสั่งสำคัญ

### 1. ระบบบอทอัตโนมัติ (`@bot` / `@autoplay`)

* **เงื่อนไขสำคัญ:** ตัวละคร**ต้องมีไอเทม  Merchant Blessing (พรแห่งพ่อค้า) อยู่ในตัว** จึงจะสามารถเปิดใช้งานคำสั่งได้
* พิมพ์ **`@bot`** หรือ **`@autoplay`** ในช่องแชทเพื่อเปิดระบบ
* ระบบจะทำการใช้สกิลที่ผู้เล่นวางไว้ใน **ปุ่มลัดตัวเลข 1 ถึง 4 (Quick Slots 1-4)** ตามลำดับคูลดาวน์
* หากไม่มีสกิลในช่อง 1 ถึง 4 พร้อมใช้งาน ระบบจะใช้การโจมตีธรรมดา (Attack) เป็นทางเลือกสำรอง
* ตัวละครจะทำการติดตามและเทเลพอร์ตเข้าหามอนสเตอร์ในระยะอย่างปลอดภัย (Guarded Blink Pursuit)

### 2. วาร์ปด่วนและร้านค้าด่วน (`@qm` และ `@sale`)

* ไม่ว่าจะอยู่ที่แผนที่ไหน หากช่องเก็บของเต็ม สามารถพิมพ์ `@sale` เพื่อเคลียร์ไอเทมขยะ แลกเป็นเงิน Meso ได้ทันที
* พิมพ์ `@qm` เพื่อเปิดหน้าต่าง Quick Move เดินทางไปยังเมืองหลัก หรือดันเจี้ยนบอสได้อย่างสะดวกรวดเร็ว
